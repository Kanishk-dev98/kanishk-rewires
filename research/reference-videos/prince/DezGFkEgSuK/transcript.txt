This GitHub repo turns every part of an AI agent into a plugin, and it comes straight from DeepSeek. This is day two of finding repositories you should know about, and it's called DeepSeek Harness. It's DeepSeek's own open source agent harness, so it's the same kind of tool as Claude Code, the layer around the model that actually does the work. Except here, everything is a plugin. That means you can swap pieces out or build your own, and the community has already built desktop apps and a whole list of plugins for it. You can try it with one npx command that opens a web UI, but it's still a developer preview, so expect things to break.
