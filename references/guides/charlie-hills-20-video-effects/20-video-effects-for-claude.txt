20 video effects for Claude
I recorded one take and Claude built all 20 of these effects on top of it. Here
they are as 20 free skills, plus the one line that installs them. Each one takes
your own talking-head clip and gives you an MP4 back.




     S TA R T H E R E

     Install the pack with one line, set up the engine once, then run /spotlight on a
     short clip of yourself. On my Mac mini a 5.5-second clip came back in 19 seconds.
     That proves the whole chain works before you try the other 19.




1. The one line that installs them
You need Claude Code (Codex works too), plus ffmpeg , Node 18 or newer and Python 3.
All free. Paste this into Terminal:

  Terminal


  npx skills add charlie947/reel-editing-skills -g -a claude-code -s '*' -y
That puts all 41 skills in the pack into ~/.claude/skills/ : the 20 effects, the shared
engine they run on, and 20 more editing skills. Keep the -g . Without it the skills only go
into the folder you are standing in, and the effect cards point at ~/.claude/skills .


  NO NPX? COPY THEM BY HAND

   git clone https://github.com/charlie947/reel-editing-skills.git , then cp -R
  reel-editing-skills/skills/* ~/.claude/skills/ . On Codex, leave out -a claude-
  code -y and pick Codex from the list it shows you.




2. Set up the engine once
All 20 effects run on one shared engine called video-effects . It needs a headless
Chrome (Puppeteer) to draw the frames, and a free local model (RobustVideoMatting) to
cut you out of the shot.

  Terminal, once


  cd ~/.claude/skills/video-effects
  npm i puppeteer
  python3 -m pip install torch torchvision pillow numpy



The cut-out model downloads once from GitHub the first time an effect needs it. It runs
on Apple Silicon, an NVIDIA card or the CPU (slow).


  THE CHECK

  Run node ~/.claude/skills/video-effects/run.cjs list . A working install prints
  20 numbered lines, from grid-dive 1.03s down to head-pop-out to the end .
  Then add --check to any effect on your clip. A good result ends with check
  passed: spotlight loads and plays from 0.60s on your clip . If you see
   puppeteer not found instead, the npm i step ran in the wrong folder.

3. The first thing to try (about three minutes)
Film 4 to 6 seconds of yourself talking, head and shoulders in shot, with space above
your head. Then in Claude Code type /spotlight and name the file. Or run it yourself:

   Terminal


   node ~/.claude/skills/video-effects/run.cjs spotlight my-clip.mp4 spotlight.mp4



Spotlight is a good first test because it needs no cut-out frames. When that works, run
 /head-pop-out . It is an ending, so it holds to the last frame of your clip. Keep that clip
short, because it cuts you out on every frame from the start of the effect.



4. All 20, grouped by the job they do
Every effect plays once, then hands back to your shot. You get a 1080x1920, 30fps H.264
file with your audio kept, the same length as your clip.

5. The commands, ready to paste
  Terminal. Swap my-clip.mp4 for your file


  # the engine, once per command
  E=~/.claude/skills/video-effects/run.cjs


  # stop the scroll
  node $E title-orbit my-clip.mp4 title-orbit.mp4 --words "BIG NEWS"
  node $E portal my-clip.mp4 portal.mp4
  node $E spotlight my-clip.mp4 spotlight.mp4
  node $E vertigo my-clip.mp4 vertigo.mp4
  node $E clone-room my-clip.mp4 clone-room.mp4


  # move between two points
  node $E grid-dive my-clip.mp4 grid-dive.mp4
  node $E infinite-zoom my-clip.mp4 infinite-zoom.mp4
  node $E cube-spin my-clip.mp4 cube-spin.mp4
  node $E tile-tunnel my-clip.mp4 tile-tunnel.mp4
  node $E shatter my-clip.mp4 shatter.mp4
  node $E liquid-glass my-clip.mp4 liquid-glass.mp4
  node $E magnifying-lens my-clip.mp4 magnifying-lens.mp4


  # show the screen, the app or the prompt
  node $E screen-in-screen my-clip.mp4 screen-in-screen.mp4
  node $E phone-fan my-clip.mp4 phone-fan.mp4
  node $E pull-back-reveal my-clip.mp4 pull-back-reveal.mp4 --words "Your clip"

The options every effect takes

Option              What it does

--at 1.2            When the effect starts, in seconds. Default 0.6s, earlier on a short clip


--len 1.5           How long it plays. Each effect has its own default (the Length column above)


 --words            The words it shows, for the six effects with a Words limit. Longer text is cut
"..."
 --from 4 --to        Use only this part of your clip
9


--stage blue          The studio colour behind you: white (default), blue or grey

--no-fit              Keep your own framing. By default your head is scaled and centred where
                      the effects expect it


--check               Fit and load the effect only, no render. Takes seconds


--keep                Keep the work files in a folder beside the output




6. Three ways I would use them

  01   A hook in the first second. Put /title-orbit with your two-word topic at --
       at 0.3 on the opening of a reel.


  02   A turn between two points. Cut your take where the second point starts, and
       run /cube-spin or /grid-dive on that part with --from and --to .


  03   An ending. Run /head-pop-out on the last 3 seconds with your call to action in
          --words .



One effect per beat is plenty. Do not stack all 20 in one video.

   W H AT YO U G E T, H O N E S T LY

   I ran all 20 on one 5.5-second clip of me, and every one finished. On your clip, each
   effect plays once at full size and hands back to your shot. These skills get you the
   effects. They do not cut your take, add captions or mix music. The other 20 skills in
   the pack do those jobs.
