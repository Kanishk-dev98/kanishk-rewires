# Source ledger: ChatGPT works inside Chrome tabs (Chat and Work modes), Oct 2026

Researched: 2026-10-18

- **c1** (fact, event n/a): On Oct 15, 2026 OpenAI updated the ChatGPT Chrome extension: Chat mode reads across open tabs (compare products, summarize); Work mode can control tabs to fill forms, send messages, download files and group tabs.

- **c2** (fact, event n/a): Official setup: in the ChatGPT desktop app open Settings > Computer Use, select the browser, install the extension from its store page, confirm it shows Manage, then start a Work or Codex chat and @-mention the browser.
