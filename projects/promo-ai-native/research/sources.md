## Open questions

- Does Outship produce numeric candidate scores/rankings, or qualitative rubric reports only? Site shows rubric analysis but no score.
- Is the analysis performed by AI agents? Site says sessions are 'analyzed' but does not name the analyzer.
- Can customers define custom rubric dimensions (e.g., the storyline's 8: code quality, problem decomposition, adaptability, testing approach, tech stack decisions, iterative mindset, verifies AI output, debugging instinct)?
- Throughput limits: any stated cap or support for sending to 'hundreds' of candidates at once?
- Is there a free task-creation flow from a written project brief, or only GitHub repo import?
- Official press kit / brand guidelines: none found; logo wordmark was rebuilt from the site's header (mark SVG path + 'outship' set in the site's own Saans Medium font).
