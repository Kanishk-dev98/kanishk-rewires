On 2026-10-20 the user said the covers look "so conservative, so much AI-stick… so much things filling it". They want them minimalist, good and catchy, in the brand theme, so a feed visitor instantly knows what's inside the reel. They also asked why reels aren't using the brand's light colour. The brand kit has cream #F6F4ED, stone #D9D6CC and pale lime #E8FFB8. They asked to make the Harness² reel in the light theme, because components and motion look better on light.

**Why:** Busy template covers read as generic AI output and don't communicate the topic at a glance. An all-dark feed is monotonous, and light acts show UI components better.

**How to apply:**
- **Covers:** one hero visual that *is* the topic (a product mark, an object or a single UI element), a 3-5 word headline with one accent word, generous negative space, and a small kanishk.rewires mark. No pixel grid, no stacked pills, no kicker plus tool pill plus site line all at once. Keep them 9:16 and grid-safe (centre 3:4).
- **Reels (default for now, set 2026-10-22):** make reels in the light theme by default, as the user asked: "from now we are going to make reels in light theme… for some time at least". Use the light theme (cream canvas, charcoal type, lime as a fill or highlight with dark text, deep green #4C8C00 for lines on cream) when it suits the components. Mix light and dark acts. Still no grey canvases.
- This supersedes the "pixel grid + tool pill" look in [[feedback-cover-grid-safe]] (grid-safety still applies).
