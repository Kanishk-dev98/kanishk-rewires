On 2026-10-18, after the ChatGPT in Chrome reel (the second video in the "So simple, only 5 steps, STEP 1..5" tutorial format after linkedin-automation-claude), the user said "from next time, we are not going to use the same type of format". They also said that when something is narrated, the text sometimes comes out two times for a single thing, and that this needs care.

**Why:** Two reels already use that structure, so a third one makes the feed look repetitive. Duplicate text (a kinetic on-screen line saying the same words as the burned-in caption) looks cluttered and cheap.

**How to apply:**
- For each new reel, pick a different structure: a cinematic news format, a single-UI walkthrough, a myth vs reality piece, a before/after, a POV demo, or a comparison. Don't use tutEasy ("only N steps") or the numbered StepHeader again unless the user asks for it.
- One text layer per moment. If burned-in captions are on, on-screen lines show different information (labels, numbers, UI) and never repeat the spoken words. Or turn captions off for that scene, or overall, when the visual text already carries the line.
- Check the board for any frame where the caption and an on-screen line say the same thing.
