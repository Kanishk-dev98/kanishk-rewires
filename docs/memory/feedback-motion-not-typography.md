On 2026-10-17 the user rejected the first Kanishk.Rewires sample (Klarna), which was built only from typography scenes. Their words: "only a typography video... we are not going to do this kind of video", "looks very generic, not cool", and it lacked "good graphic motions" that match what is being said.

**Why:** The user wants premium motion design. Every scene should visually demonstrate the narration with animated interfaces, cursor actions, diagrams, data moving and camera moves, not text on a background.

**How to apply:**
- Every scene needs a demonstrative visual: UI mockups, workflows, charts and objects in motion, with a camera (tilt, focus zoom, parallax). Typography supports it and is never the whole scene.
- The Kanishk.Rewires branding should be **small**: a small corner mark during the video and a compact outro lockup. No big wordmark moments.
- See [[feedback-video-quality]] and [[user-alok-kanishk-rewires]].
